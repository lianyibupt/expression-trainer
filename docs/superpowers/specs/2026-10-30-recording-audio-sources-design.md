# 录音声音来源切换

用户已于 2026-10-30 确认两个独立开关方案，并授权实现。

- 在实时字幕的录音控制区显示“麦克风输入”和“系统输出”两个按钮，录音前、录音中及暂停时均可选择。保留现有初始默认值；同一应用窗口内的新会议沿用最近选择。
- 关闭麦克风立即关闭录音混音入口并停止本应用的麦克风轨道；不会操作会议软件的麦克风。开启麦克风重新申请并连接输入。
- 系统输出使用现有 Native helper、虚拟输入、Electron loopback 路径。关闭时清空排队音频并停止采集；开启失败显示错误并保持关闭，不自动开启麦克风。
- 通过两个独立 Web Audio 输入通道及零值驱动源处理声音。系统输出模式不依赖麦克风存在；两个开关均关闭时写入静音，保留当前录音时间线。
- 同样的来源选择适用于自动会议监听，避免关闭麦克风后被监听逻辑重新打开。
- 来源变更只影响之后的采样。已经录入的声音不会被删除；若会议软件把自己的声音回放到系统输出，那部分仍属于输出音频。
- 用来源路由模块管理设备轨道、Native PCM 队列、异步开启及关闭清理；界面负责按钮和提示，ASR、最终稿、保存流程保持现有接口。
- 验收：纯系统输出无需请求麦克风；关闭输入后后续样本无麦克风成分；关闭输出清空旧缓存；开启失败不回退到麦克风；停止期间完成的设备请求被释放；录音与监听切换均释放资源。
